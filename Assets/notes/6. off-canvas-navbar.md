# Responsive Navigation with Offcanvas Menu


The concept name you are looking for is R`esponsive Navigation with Offcanvas` Menu.



```
Desktop
→ Normal expanded navbar

Mobile
→ Hamburger ☰
→ Click
→ Side Drawer / Offcanvas Menu

```
### How it works
```
                      Responsive Navbar
                         │
              ┌──────────┴──────────┐
              │                     │
           Mobile                 Desktop
              │                     │
              ↓                     ↓
         ☰ Hamburger           Normal Menu
              │
              ↓
       Click Hamburger
              │
              ↓
      Bootstrap Offcanvas
              │
              ↓
    ┌──────────────────┐
    │ Home             │
    │ About            │
    │ Services         │
    │ Contact          │
    └──────────────────┘

```
### Mobile Drawer Example
```
<nav class="navbar navbar-dark bg-dark">
    <div class="container">

         <!-- Mobile Menu Button -->
        <button class="navbar-toggler d-lg-none"
                type="button"
                data-bs-toggle="offcanvas"
                data-bs-target="#mobileMenu">
            <span class="navbar-toggler-icon"></span>
        </button>
        
        <a class="navbar-brand" href="#">
            MySite
        </a>

       

        <!-- Desktop Menu -->
        <div class="d-none d-lg-block">
            <ul class="navbar-nav flex-row">
                <li class="nav-item mx-2">
                    <a class="nav-link" href="#">Home</a>
                </li>
                <li class="nav-item mx-2">
                    <a class="nav-link" href="#">About</a>
                </li>
                <li class="nav-item mx-2">
                    <a class="nav-link" href="#">Services</a>
                </li>
                <li class="nav-item mx-2">
                    <a class="nav-link" href="#">Contact</a>
                </li>
            </ul>
        </div>

    </div>
</nav>

<!-- Mobile Drawer -->
<div class="offcanvas offcanvas-start"
     tabindex="-1"
     id="mobileMenu">

    <div class="offcanvas-header">
        <h5>MySite</h5>

        <button type="button"
                class="btn-close"
                data-bs-dismiss="offcanvas">
        </button>
    </div>

    <div class="offcanvas-body">

        <a class="nav-link mb-3" href="#">Home</a>
        <a class="nav-link mb-3" href="#">About</a>
        <a class="nav-link mb-3" href="#">Services</a>
        <a class="nav-link mb-3" href="#">Contact</a>

    </div>
</div>
```
