# Bootstrap Navbar

A Bootstrap Navbar is used to create a responsive navigation bar for a website.

### Important Bootstrap Navbar Classes

| Class                 | Meaning                        |
| --------------------- | ------------------------------ |
| `navbar`              | Creates a navbar               |
| `navbar-brand`        | Logo / Website name            |
| `navbar-expand-lg`    | Expands menu at `lg` and above |
| `navbar-dark`         | Dark navbar theme              |
| `navbar-light`        | Light navbar theme             |
| `bg-dark`             | Dark background                |
| `bg-success`          | Green background               |
| `navbar-nav`          | Navigation menu container      |
| `nav-item`            | Individual menu item           |
| `nav-link`            | Navigation link                |
| `navbar-toggler`      | Mobile hamburger button        |
| `navbar-toggler-icon` | Hamburger icon                 |
| `collapse`            | Show/hide menu                 |
| `offcanvas`           | Side drawer menu               |


### Basic Navbar
```
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">

    <div class="container">

        <!-- Website Logo / Name -->
        <a class="navbar-brand" href="#">
            MySite
        </a>

        <!-- Menu -->
        <div class="navbar-nav">
            <a class="nav-link" href="#">Home</a>
            <a class="nav-link" href="#">About</a>
            <a class="nav-link" href="#">Services</a>
            <a class="nav-link" href="#">Contact</a>
        </div>

    </div>

</nav>
```
