# 1. What is Carousel?

- A Bootstrap Carousel is a slideshow component used to display multiple images or content one after another

### Commonly used for:

- Image sliders
- Product banners
- Offers
- Website home page banners
- News slides

```
    Image 1  →  Image 2  →  Image 3
    ←           →           →
```

### Basic Carousel Structure

```
<div id="myCarousel" class="carousel slide">

    <!-- Slides -->

</div>
```

### Important Classes


| Class            | Purpose                  |
| ---------------- | ------------------------ |
| `carousel`       | Creates carousel         |
| `slide`          | Adds sliding animation   |
| `carousel-inner` | Container for slides     |
| `carousel-item`  | Individual slide         |
| `active`         | Displays the first slide |

### Carousel Concept in One Diagram

```
<div class="carousel slide">
        │
        ├── Indicators
        │
        ├── carousel-inner
        │       │
        │       ├── carousel-item active
        │       ├── carousel-item
        │       └── carousel-item
        │
        ├── Previous Button
        │
        └── Next Button

```
### Simple Carousel
```

<div id="myCarousel" class="carousel slide" data-bs-ride="carousel">

    <div class="carousel-inner">

        <div class="carousel-item active">
            <img src="image1.jpg" class="d-block w-100">
        </div>

        <div class="carousel-item">
            <img src="image2.jpg" class="d-block w-100">
        </div>

        <div class="carousel-item">
            <img src="image3.jpg" class="d-block w-100">
        </div>

    </div>
     <!-- previous Button -->
    <button class="carousel-control-prev"
        type="button"
        data-bs-target="#myCarousel"
        data-bs-slide="prev">

       <span class="carousel-control-prev-icon"></span>

    </button>

      <!-- Next Button -->
    <button class="carousel-control-next"
            type="button"
            data-bs-target="#myCarousel"
            data-bs-slide="next">

        <span class="carousel-control-next-icon"></span>

    </button>

</div>




```



### Complete Carousel 
```



    <div id="myCarousel" 
         class="carousel slide" 
         data-bs-ride="carousel">

        <!-- Indicators / Dots -->
        <div class="carousel-indicators">

            <button type="button"
                    data-bs-target="#myCarousel"
                    data-bs-slide-to="0"
                    class="active">
            </button>

            <button type="button"
                    data-bs-target="#myCarousel"
                    data-bs-slide-to="1">
            </button>

            <button type="button"
                    data-bs-target="#myCarousel"
                    data-bs-slide-to="2">
            </button>

        </div>


        <!-- Slides -->
        <div class="carousel-inner">

            <div class="carousel-item active">
                <img src="image1.jpg" class="d-block w-100">
            </div>

            <div class="carousel-item">
                <img src="image2.jpg" class="d-block w-100">
            </div>

            <div class="carousel-item">
                <img src="image3.jpg" class="d-block w-100">
            </div>

        </div>


        <!-- Previous Button -->
        <button class="carousel-control-prev"
                type="button"
                data-bs-target="#myCarousel"
                data-bs-slide="prev">

            <span class="carousel-control-prev-icon"></span>

        </button>


        <!-- Next Button -->
        <button class="carousel-control-next"
                type="button"
                data-bs-target="#myCarousel"
                data-bs-slide="next">

            <span class="carousel-control-next-icon"></span>

        </button>

    </div>


    
```
