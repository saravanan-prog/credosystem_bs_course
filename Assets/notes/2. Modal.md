# Modal

Modal opens a popup window on top of the current page.

### 1 Bootstrap Modal diagram
```
┌───────────────────────────────────────────────┐
│                  WEB PAGE                     │
│                                               │
│        ┌──────────────────────┐               │
│        │   Open Modal Button  │               │
│        └──────────┬───────────┘               │
│                   │                           │
│                   │ Click                     │
│                   ▼                            │
│        ┌─────────────────────────┐             │
│        │     MODAL CONTAINER     │             │
│        │       .modal            │             │
│        │                         │             │
│        │  ┌───────────────────┐  │             │
│        │  │   MODAL DIALOG     │  │             │
│        │  │  .modal-dialog     │  │             │
│        │  │                    │  │             │
│        │  │ ┌───────────────┐  │  │             │
│        │  │ │ MODAL CONTENT │  │  │             │
│        │  │ │               │  │  │             │
│        │  │ │ HEADER     ✕  │  │  │             │
│        │  │ │               │  │  │             │
│        │  │ │ BODY          │  │  │             │
│        │  │ │               │  │  │             │

│        └─────────────────────────┘             │
└───────────────────────────────────────────────┘

```
### 2 Bootstrap Modal Structure

```
   .modal
   │
   └── .modal-dialog
          │
          └── .modal-content
                 │
                 ├── .modal-header
                 │      ├── .modal-title
                 │      └── Close Button
                 │
                 ├── .modal-body
                 │
                 └── .modal-footer

```

```
<button class="btn btn-primary"
        data-bs-toggle="modal"
        data-bs-target="#myModal">
    Open Modal
</button>

<div class="modal fade" id="myModal">

    <div class="modal-dialog">

        <div class="modal-content">

            <div class="modal-header">
                <h5 class="modal-title">My Modal</h5>
                <button class="btn-close"
                        data-bs-dismiss="modal">
                </button>
            </div>

            <div class="modal-body">
                This is my modal content.
            </div>

        </div>

    </div>

</div>
```
