# 🔝 Bootstrap Navbar

A Navbar is used to create a responsive navigation menu for your website (top bar with links, logo, etc.).

#### 🔹Basic Navbar Example

```
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container-fluid">
    
    <!-- Brand -->
    <a class="navbar-brand" href="#">MyApp</a>

    <!-- Toggle button (for mobile) -->
    <button class="navbar-toggler" type="button" 
      data-bs-toggle="collapse" data-bs-target="#navbarNav">
      <span class="navbar-toggler-icon"></span>
    </button>

    <!-- Links -->
    <div class="collapse navbar-collapse" id="navbarNav">
      <ul class="navbar-nav">
        <li class="nav-item">
          <a class="nav-link active">Home</a>
        </li>
        <li class="nav-item">
          <a class="nav-link">About</a>
        </li>
        <li class="nav-item">
          <a class="nav-link">Contact</a>
        </li>
      </ul>
    </div>

  </div>
</nav>
```


🔍 Key Parts Explained
🟢 navbar

Main container for the navbar

🟢 navbar-expand-lg
Expands on large screens
Collapses on mobile
🟢 navbar-brand

Your logo or website name

🟢 navbar-toggler

Hamburger menu button (for mobile view)

🟢 collapse navbar-collapse

Wraps links → makes them collapsible

🟢 navbar-nav & nav-item

Structure for navigation links

🎨 Navbar Colors
navbar-light bg-light
navbar-dark bg-dark
bg-primary, bg-success, etc.
