# BS- Flex


These are layout utility classes from Bootstrap used together for Flexbox alignment.

### 1. `d-flex` - Enable Flex
```
<div class="d-flex">
    ...
</div>
```


 ### 2. `flex-row` -  Direction

```
  <div class="d-flex flex-row"> 
    → → →

  <div class="d-flex flex-column">
    ↓
    ↓
    ↓

  <div class="d-flex flex-row-reverse">
   ← ← ←

  <div class="d-flex flex-column-reverse">
    ↑
    ↑
    ↑

```

### 3. Justify Content  [main axis]

Start
```
<div class="d-flex justify-content-start">  
 [1][2][3]........
```
Center
```
<div class="d-flex justify-content-center">
......[1][2][3]......
```
End
```
<div class="d-flex justify-content-end">
........[1][2][3]
```
Space Between
```
<div class="d-flex justify-content-between">
[1].......[2].......[3]
```
### 4. Align Items [cross axis]

```
  <div class="d-flex align-items-start">
  <div class="d-flex align-items-end">
  <div class="d-flex align-items-center">
```

### 5. Flex Wrap
`Wrap` - Items can move to the next line.
```
  <div class="d-flex flex-wrap">
```
`No wrap`  
```
  <div class="d-flex flex-nowrap">
```
`Reverse wrap` 

```
  <div class="d-flex flex-wrap-reverse">
```
### 6. Gap

```
<div class="d-flex gap-3">

    gap-0
    gap-1
    gap-2
    gap-3
    gap-4
    gap-5

```
