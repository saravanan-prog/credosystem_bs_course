These are layout utility classes from Bootstrap used together for Flexbox alignment.

### 🔹 d-flex
```
CSS: display: flex;
📐 Makes the container a flexbox
```

### 🔹 justify-content-between

```
    CSS: justify-content: space-between;
    ↔️ Distributes items horizontally
```
First item goes to the start, last item to the end
Space is added between items




### 🔹 align-items-center
```
CSS: align-items: center;

↕️ Aligns items vertically (center) inside the container
```

### 💡 Combined Effect

```
<div class="d-flex justify-content-between align-items-center">
  <div>Left</div>
  <div>Right</div>
</div>
```
