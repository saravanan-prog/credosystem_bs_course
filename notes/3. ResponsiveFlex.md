# 🔑 1. Know the Breakpoints

Bootstrap uses these screen sizes:

| Prefix | Screen Size |
| ------ | ----------- |
| `sm`   | ≥576px      |
| `md`   | ≥768px      |
| `lg`   | ≥992px      |
| `xl`   | ≥1200px     |
| `xxl`  | ≥1400px     |

### 👉 Format:

```
property-{breakpoint}-{value}

```

## 🔹 2. Responsive Flex Direction

Change layout direction based on screen:

```
<div class="d-flex flex-column flex-md-row flex-xl-column">
</div>

Mobile  → column ⬇️
Tablet  → row ➡️
XL      → column again
```
### 🔹 3. Responsive Justify Content

Control horizontal alignment:

```
<div class="d-flex justify-content-center justify-content-md-between justify-content-xl-around">

</div>

Mobile  → center
md      → space-between
xl      → space-around
```


 🔹 4. Responsive Align Items

Control vertical alignment:
```
<div class="d-flex align-items-start align-items-md-center align-items-xl-end">
</div>
```

### 🔹 5. Responsive Wrapping

```
<div class="d-flex flex-wrap flex-md-nowrap">
</div>
Small   → wrap
md+     → no wrap
```


### 🔹 6. Responsive Order (Super Useful 🔥)

Change element order:

```
<div class="d-flex">
  <div class="order-2 order-md-1">First</div>
  <div class="order-1 order-md-2">Second</div>
</div>
👉 Items swap positions on different screens
```



### 🔹 7. Responsive Alignment per Item

```
<div class="d-flex">
  <div class="align-self-start align-self-md-center">Item</div>
</div>
```

## 🧠 Real Example (Common Layout)
```
<div class="d-flex flex-column flex-md-row justify-content-between align-items-center">
  <div>Logo</div>
  <div>Menu</div>
</div>

✔ Mobile → stacked
✔ Tablet+ → horizontal navbar
```
