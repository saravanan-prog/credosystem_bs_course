 # display utility classes


 - These are `display utility classes` from `Bootstrap` 
 - Each one controls `how an element` is `rendered` on the page.



#### ` d-none`

- CSS: `display: none;`
- ❌ Hides the element completely (it won’t take any space)



####  `d-block`


- CSS: `display: block;`
- Makes the element behave like a block (takes full width by default)


#### `d-inline`

- CSS: `display: inline;`
- 🧵 Element stays in line with text (no width/height control)


####  `d-inline-block`

CSS: `display: inline-block`;


#### Bootstrap also has responsive versions, like:

```
d-sm-none
d-md-block


 These apply styles based on screen size.
```
