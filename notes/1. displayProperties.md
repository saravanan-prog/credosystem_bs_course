 # display utility classes


 - These are display utility classes from Bootstrap 
 - each one controls how an element is rendered on the page.

## Here’s a simple breakdown:

#### 🔹 d-none
```
CSS: display: none;
❌ Hides the element completely (it won’t take any space)
```


#### 🔹 d-block

```
CSS: display: block;
📦 Makes the element behave like a block (takes full width by default)
```

#### 🔹 d-inline

```
CSS: display: inline;
🧵 Element stays in line with text (no width/height control)
```

#### 🔹 d-inline-block
```
CSS: display: inline-block;
```
## 🔲 Inline element but allows width & height

#### 🔹 d-flex

```
CSS: display: flex;

📐 Turns element into a flex container (great for layout)

```
#### 🔹 d-inline-flex
```
CSS: display: inline-flex;
```

#### 📐 Flex container but behaves inline (doesn’t take full width)

 💡 Example

```
<div class="d-flex">
  <div>Item 1</div>
  <div>Item 2</div>
</div>

👉 Items will be aligned in a row using Flexbox.

```

#### Bootstrap also has responsive versions, like:

```
d-sm-none
d-md-block
d-lg-flex

👉 These apply styles based on screen size.
```
