# 🧩 1. Form Controls

Form controls are the basic input elements users interact with.

#### Common types:
- Text input
- Password input
- Email input
- Number input
- File upload
- Select dropdown
- Checkbox & radio buttons
- Textarea

#### Example:
```
<form>
  <div class="mb-3">
    <label class="form-label">Email</label>
    <input type="email" class="form-control" placeholder="Enter email">
  </div>

  <div class="mb-3">
    <label class="form-label">Password</label>
    <input type="password" class="form-control" placeholder="Password">
  </div>
  <div>
     <button type="submit" class="btn btn-primar"> 
  </div>
</form>
```

## Key classes:

Form input  → `form-control`
Form label  → `form-label` 

checkbox / radio wrapper  → `form-check-inline`
chekbox label → `form-check-label`
checkbox / radio  → `form-check-input`



 selectbox  → `form-select`
