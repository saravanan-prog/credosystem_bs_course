# 📦 Bootstrap Margin & Padding

👉 Bootstrap uses shortcut classes to control spacing.

#### 🎯 Basic Format

```
    {property}{side}-{size}
    
```



# Copyable Cheat Sheet

```
    m  = margin
    p  = padding

    t = top
    b = bottom
    s = left
    e = right
    x = left + right
    y = top + bottom

    0-5 = size
    auto = auto margin

```
