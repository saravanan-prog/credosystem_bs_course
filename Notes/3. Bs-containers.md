# 📦 container vs container-fluid

Both are used as the main wrapper in Bootstrap layouts.

#### 📌 1. container

👉 Fixed-width container (changes based on screen size)

#### ✅ Example
```
<div class="container">
  <h1>Content</h1>
</div>
```

#### 🎯 Behavior
- Centered on screen
- Has left & right spacing (margin)
- Width changes at breakpoints

#### 📱 Example sizes
 
 Breakpoint   | Screen Size (min-width) | Container Max Width
-------------|--------------------------|--------------------
Default      | <576px                   | 100%
sm           | ≥576px                   | 540px
md           | ≥768px                   | 720px
lg           | ≥992px                   | 960px
xl           | ≥1200px                  | 1140px
xxl          | ≥1400px                  | 1320px




#### 💡 Use when:
- You want clean centered layout
- Normal websites (landing pages, forms)

#### 📌 2. container-fluid

👉 Full-width container (always 100%)

#### ✅ Example

```
<div class="container-fluid">
  <h1>Full Width</h1>
</div>
```
#### 🎯 Behavior

- Takes entire width of screen
- No side margins

#### 💡 Use when:
- You want full-width layout
- Dashboards
- Banners
- Background sections


#### 🔥 Visual Difference

```
container:
   [     content centered     ]

container-fluid:
[content takes full width of screen]
```
#### 🚀 Real Example

```
<div class="container bg-light p-3">
  Centered Content
</div>

```
```
<div class="container-fluid bg-primary text-white p-3">
  Full Width Content
</div>
```


Feature           | container        | container-fluid
------------------|------------------|-----------------
Width             | Fixed            | 100% full width
Alignment         | Centered         | Full screen
Side Spacing      | Yes              | No
Responsive        | Yes              | Yes
Use Case          | Normal layouts   | Full-width layouts
