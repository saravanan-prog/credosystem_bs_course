# Bootstrap Position Utilities
Bootstrap provides classes to control the position of elements.

```
    position-static
    position-relative
    position-absolute
    position-fixed
    position-sticky
```
Usually you combine it with:
```
top-0
top-50
top-100

bottom-0
bottom-50
bottom-100

start-0
start-50
start-100

end-0
end-50
end-100
```

Example: position move to absolute

```
<div class="position-relative" style="height:200px;">

    <div class="position-absolute top-0 end-0">
        Box
    </div>

</div>

```
