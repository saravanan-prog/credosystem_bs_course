# 🎨 Bootstrap Color Classes

Bootstrap provides predefined color names you can use directly.

# 📋 Copyable Bootstrap Colors Table

Class       | Meaning
------------|----------------
primary     | Blue (main color)
secondary   | Gray
success     | Green
danger      | Red
warning     | Yellow
info        | Cyan
light       | Light gray
dark        | Dark / Black




#### 📌 Text Colors

```
    <p class="text-primary">Primary</p>
    <p class="text-success">Success</p>
    <p class="text-danger">Danger</p>
    <p class="text-warning">Warning</p>
    <p class="text-info">Info</p>
    <p class="text-dark">Dark</p>
    <p class="text-light bg-dark">Light</p>
    <p class="text-muted">Muted</p>

```


#### 📌 Background Colors

```
    <div class="bg-primary text-white">Primary</div>
    <div class="bg-success text-white">Success</div>
    <div class="bg-danger text-white">Danger</div>
    <div class="bg-warning">Warning</div>
    <div class="bg-info text-white">Info</div>
    <div class="bg-dark text-white">Dark</div>
    <div class="bg-light">Light</div>
```
