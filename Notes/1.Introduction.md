## Bootstrap

-  `Bootstrap is a mobile-first CSS framework` 
- that provides `pre-built components` and a `responsive grid system` for `faster web development`.



###  What Bootstrap Provides
- Ready-made classes ( `border`, `btn`,` text-primary`, `text-center`, `bg-primary`)
- Grid system (`layout`)
- Components (`buttons`, `navbar`, `cards`)
- Utilities (`spacing`, `colors`, `flex`)
- JavaScript features (`modals`, `dropdowns`)

## Booststrap CDN Configuration
- CDN (`Content Delivery Network`) is a system of servers
- that deliver files (`CSS`, `JS`, `images`) from the `nearest location` to the `user` 🌍

####  Why use CDN?
- ⚡ Faster loading
- 📦 No need to download files
- 🌍 Works globally
- 👍 Easy setup

#### Setup - 1 Add the CSS inside `<head>`
```
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
```
#### Setup - 2 Add the JS inside `<body>`

```
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
```
