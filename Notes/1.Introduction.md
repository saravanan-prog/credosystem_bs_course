## 📌 What is Bootstrap?

- Bootstrap is a popular front-end CSS framework used to build responsive and modern websites quickly.


## 🚀 Why use Bootstrap?

#### ⚡ 1. Fast UI Development
Ready-made classes like:
```
   <button class="btn btn-primary">Click</button>
```

👉 No need to write custom CSS for buttons

#### 📱 2. Mobile-First Design

Designed for small screens first, then scaled up

```
    <div class="col-12 col-md-6"></div>
```

👉 Full width on mobile
👉 Half width on tablet/desktop


### 🧱 What Bootstrap Provides
    - ✅ Grid system (layout)
    - ✅ Components (buttons, navbar, cards)
    - ✅ Utilities (spacing, colors, flex)
    - ✅ JavaScript features (modals, dropdowns)

### 💡 Real-life analogy

 ```
    👉 Bootstrap is like a ready-made UI toolkit
    ( Instead of building a chair 🪑 from wood, you just assemble it)
```
