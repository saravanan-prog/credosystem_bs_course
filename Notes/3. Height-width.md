# BS height and Width

    In Bootstrap, height (h-*) and width (w-*) utilities let you quickly control element size without custom CSS.

#### 🔹 Width Utilities (w-*)

```
✅ Common classes:

w-25    <!-- 25% width -->
w-50    <!-- 50% width -->
w-75    <!-- 75% width -->
w-100   <!-- 100% width -->
w-auto  <!-- auto width -->

```
#### 👉 Example:

```
    <div class="w-50 bg-primary text-white">Half width</div>
```

#### 🔹 Height Utilities (h-*)


```
✅ Common classes:

    h-25    <!-- 25% height -->
    h-50    <!-- 50% height -->
    h-75    <!-- 75% height -->
    h-100   <!-- 100% height -->
    h-auto  <!-- auto height -->
```
#### 👉 Example:

```
<div style="height:200px;">
  <div class="h-100 bg-success text-white">Full height</div>
</div>
```
