# Bs-border

In CSS (especially when using frameworks like Bootstrap), bs-border or border refers to applying borders to elements.

Here’s what you likely mean:

🔹 Basic Bootstrap Border Classes

### Bootstrap provides simple utility classes for borders:

```
    border      → adds a border on all sides
    border-0    → removes border
    border-top, 
    border-end, 
    border-bottom, 
    border-start → specific sides
```
### 🔹 Border Colors

```
    border-primary
    border-secondary
    border-success
    border-danger
    border-warning
    border-info
    border-light
    border-dark
```

### 🔹 Border Width

```
border-1 to border-5
```

### 🔹 Border Radius (rounded corners)

```
rounded
rounded-circle
rounded-pill
rounded-0
```
