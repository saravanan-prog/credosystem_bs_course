# 📌 What is Grid System?

- The Bootstrap Grid System is used to create responsive layouts using rows and columns.

- 👉 It is based on a 12-column layout

#### 🧱 Basic Structure (VERY IMPORTANT)

```
    <div class="container">
        <div class="row">
            <div class="col">Column</div>
        </div>
    </div>
```
#### 🎯 How it works

```
    container   → main wrapper
    row         → horizontal group
    col         → columns inside row
    📊            12 Column Rule
```

👉 Bootstrap divides the page into 12 columns

```
<div class="row">
  <div class="col-6">50%</div>
  <div class="col-6">50%</div>
</div>

✔ 6 + 6 = 12
```

#### 🔢 Column Sizes
```
<div class="col-4">33%</div>
<div class="col-8">66%</div>
```

✔ 4 + 8 = 12

#### 📱 Responsive Grid (Most Important)

```
<div class="row">
  <div class="col-12 col-md-6 col-lg-4">Box</div>
</div>

🧠 Behavior

    📱 Mobile → full width
    📱 Tablet → half width
    💻 Desktop → one-third

```



#### 🔁 Auto Columns

```
<div class="row">
  <div class="col">1</div>
  <div class="col">2</div>
  <div class="col">3</div>
</div>
```

👉 Equal width automatically

#### 📦 Real Example

```
<div class="container mt-4">
  <div class="row">
    <div class="col-4 bg-primary text-white p-3">1</div>
    <div class="col-4 bg-success text-white p-3">2</div>
    <div class="col-4 bg-danger text-white p-3">3</div>
  </div>
</div>
```

#### 🔀 Nested Grid

```
<div class="col-6">
  <div class="row">
    <div class="col-6">Nested 1</div>
    <div class="col-6">Nested 2</div>
  </div>
</div>
```

#### 🧠 Key Points
- Always use row inside container
- Columns must be inside row
- Total columns = 12
- Mobile-first design
