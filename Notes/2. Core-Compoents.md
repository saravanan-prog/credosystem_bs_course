

#### 🚨 1. Alerts

Used to show messages (success, error, warning)

Example:
```
<div class="alert alert-success">Success!</div>
<div class="alert alert-danger">Error!</div>
```


Features:

- Dismissible alerts
- Contextual colors



#### 📊 2. Tables

Display structured data.

Example:
```
<table class="table">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Sara</td>
    <td>22</td>
  </tr>
</table>
```

Features:

- Striped (table-striped)
- Hover (table-hover)


## Responsive tables

```
<div class="table-responsive">
    <table class="table">

        <th>Age</th>
```
