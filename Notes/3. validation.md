## ✅ 3. Validation Classes

Bootstrap provides built-in validation styles.

### Basic validation example:
```
<form class="needs-validation" novalidate>
  <div class="mb-3">
    <label>Email</label>
    <input type="email" class="form-control" required>
    <div class="invalid-feedback">
      Please enter a valid email.
    </div>
  </div>

  <button class="btn btn-primary">Submit</button>
</form>
```
### Important classes:

```
needs-validation                    → enables validation styling
was-validated                       → applied after submit
is-valid                            → success state
is-invalid                          → error state
valid-feedback / invalid-feedback   → messages

```
### ⚡ Validation Behavior (JavaScript)

```
<script>
(() => {
  'use strict';
  const forms = document.querySelectorAll('.needs-validation');

  forms.forEach(form => {
    form.addEventListener('submit', event => {
      if (!form.checkValidity()) {
        event.preventDefault();
        event.stopPropagation();
      }
      form.classList.add('was-validated');
    });
  });
})();
</script>
```


### 🧠 Quick Summary
```
Form Controls  → user input elements
Input Groups   → combine inputs with addons
Validation     → show success/error feedback
```
