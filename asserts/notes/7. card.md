# Bootstrap Card
- A Bootstrap Card is a flexible container used to display content like:

```
┌──────────────────────┐
│       IMAGE          │
├──────────────────────┤
│ Product Name         │
│ Product description  │
│ ₹500                 │
│ [ Buy Now ]          │
└──────────────────────┘

Product
User profile
Course
Blog
News
Image + Text + Button

```

### Structure:

```
card
 │
 ├── card-img-top
 │
 └── card-body
       │
       ├── card-title
       │
       ├── card-text
       │
       └── button


```

### Example
```
<div class="card" style="width: 18rem;">

    <img src="image.jpg" class="card-img-top">

    <div class="card-body">

        <h5 class="card-title">
            Java Course
        </h5>

        <p class="card-text">
            Learn Java.
        </p>

        <button class="btn btn-primary">
            Learn More
        </button>

    </div>

</div>
```
